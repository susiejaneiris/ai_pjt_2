# 데이터 · 문서 출처와 이용 조건 (NF2007)

비영리 교육 과제(SSAFY AI 코어 프로젝트 2회차)에서만 사용한다. 원문은 수정하지 않고 발췌해 보여 주며, 근거마다 원문 URL을 표시한다.

| 데이터 | 출처 | 받는 방법 | 이용 조건 | 기록 위치 |
|---|---|---|---|---|
| 항목 메타데이터 (법률 108건) | 국가법령정보센터 Open API (https://open.law.go.kr) | `lawSearch.do` · `lawService.do` (target=law) | 활용 신청 후 발급한 OC 로 호출. 법령은 저작권법 제7조에 따라 보호받지 않는 저작물. 출처 표시 | `data/items.json` 의 `source` · `collected_at` |
| 외부 문서 — 조문 (법률 · 시행령) | 국가법령정보센터 Open API | `lawService.do` (target=law) | 위와 같음 | 청크 메타데이터 `url` · `date`(시행일) · `collected_at` |
| 외부 문서 — 판례 | 국가법령정보센터 Open API | `lawSearch.do` · `lawService.do` (target=prec) | 판결은 저작권법 제7조에 따라 보호받지 않는 저작물. 출처 표시 | 청크 메타데이터 `url` · `date`(선고일) |
| 외부 문서 — 법령해석례 (PDF) | 법제처, 「2024 법령해석 사례집」(상) 692쪽 · (하) 710쪽 — 공공데이터포털(https://www.data.go.kr)에서 내려받음 | `data/pdf/` 원본 → `python -m prep.casebook` → `data/casebook.json` (312건) | **공공누리 제4유형** (출처표시 + 상업적 이용금지 + 변경금지). 비영리 교육 과제로만 사용한다. 변경금지를 지키기 위해 사례 본문(질의요지 · 회답 · 이유)의 문장은 고치지 않고 그대로 발췌하며(쪽 머리글 · 각주 표시 같은 조판 요소만 분리), 근거마다 "법제처, 「2024 법령해석 사례집」(상/하), 쪽"으로 출처를 표시한다. 답변은 원문을 바꿔 다시 배포하는 것이 아니라 원문을 근거로 인용하는 형태로만 쓴다 | 청크 메타데이터 `citation` (예: 법제처, 「2024 법령해석 사례집」(하), 1149~1152쪽) |
| 외부 문서 — 생활법령 백문백답 | 법제처 「찾기쉬운 생활법령정보」 백문백답 — 공공데이터포털 Open API (생활법령백문백답서비스, SOAP) | `python -m prep.easylaw_qa` → `data/qa.json` (질문 · 답 · 관련 법령 · 원문 URL) | 공공데이터포털 인증키(DATA_GO_KR_KEY)로 호출, 초당 10건 이하. **⚠ 데이터 페이지의 이용허락범위를 확인해 여기에 적을 것.** 작성 시점(2010년~)이 오래된 답이 있어 근거에 작성일을 표시하고, 금액 · 기간 · 법 이름은 조문으로 확인되는 것만 단정 | 청크 메타데이터 `citation` (작성일 포함) · `url` |

## 공공누리 제4유형 출처 표시 문구
법령해석례 근거가 화면에 나올 때마다 아래 문구를 함께 표시한다 (`prep/casebook.py` 의 `KOGL_NOTICE`).

> 이 서비스는 공공누리 제4유형으로 개방한 '법제처, 「2024 법령해석 사례집」'을 이용하였으며, 해당 저작물은 공공데이터포털(www.data.go.kr)에서 무료로 내려받을 수 있습니다.

| 공공누리 4유형 조건 | 지키는 방법 |
|---|---|
| 출처표시 | 근거마다 "법제처, 「2024 법령해석 사례집」(상/하), 쪽" + 위 문구 |
| 상업적 이용금지 | 비영리 교육 과제로만 사용, 서비스를 유료로 제공하지 않음 |
| 변경금지 | 원문 문장을 고치지 않고 발췌해 보여 줌. 쉬운 말 풀이 · 답변은 원문을 바꾼 2차 저작물로 배포하지 않고, 원문 발췌와 쪽 번호를 함께 보여 주는 인용으로만 씀 |

## 호출 예절 (NF2006)
- 법령 API: 호출 간 최소 0.3초, 네트워크 오류 · 5xx 는 최대 3회 재시도 (`prep/law_api.py`)
- 위키백과: User-Agent `LawGuide/0.1 (연락처) python-requests`, 호출 간 최소 0.35초, 429 는 Retry-After 만큼 대기 후 재시도 (`prep/wiki_api.py`)
- 이미 수집한 검색어는 다시 호출하지 않는다 (`data/collected.json`, NF2002)

## 주의
- 법령 API 응답의 상세 링크에는 인증값(OC)이 들어 있어 화면에 쓰지 않는다. 근거 링크는 `https://www.law.go.kr/법령/{법령명}/{조문}` 형식으로 다시 만든다.
- 이 서비스의 답변은 법률 자문이 아니다. 화면에 면책 문구를 항상 표시한다.
